SenseFlow Wiring Guide

Which ESP32 pin goes where on the tank display (Monitor) and the tank sensor (Transmitter), for every sensor type and connection type, and which combinations must never be wired together.

Monitor firmware 56.1.0Transmitter firmware 55.1.0Board: ESP32-WROOM-32

Read before wiring

ESP32 pins are 3.3 V only

Never put 5 V on a GPIO. A 5 V sensor's ECHO or TX output must go through a voltage divider before GPIO34 (see each setup below).

One sensor type per board

GPIO25 and GPIO34 are shared by Trig/Echo, UART and RS485. Wire only the sensor type selected in Settings. Never leave a second sensor connected.

RS485 boards have no Long Range module

The RS485 module's RO output uses GPIO5, which is also the LoRa chip select. Remove the LoRa module from any board wired for RS485 (UART bridge or Modbus).

Use an ESP32-WROOM-32

RS485 TX is on GPIO17. On ESP32-WROVER modules GPIO16/17 are used by PSRAM and RS485 will not work.

Antenna before power

Fit the 433 MHz antenna before powering a Long Range module. Transmitting without one can damage it. LoRa modules are 3.3 V only.

Keep these pins free

GPIO6 to GPIO11 (internal flash). Avoid GPIO0, GPIO2, GPIO12 and GPIO15 (boot strapping) for anything else you add.

First power-on check

  1. Before power: check no GPIO can see more than 3.3 V, only one sensor type is connected, and RS485 boards have no LoRa module.
  2. Power on, open the setup page, and select the sensor type that is actually wired. The board restarts.
  3. Open the serial monitor at 115200 baud and type SENSOR to see the type, range and settings.
  4. SENSOR TEST takes one reading. "No reply" points at wiring or power. "Answered but no valid distance" means the target is out of range or in the blind zone.
  5. SENSOR RAW prints the bytes on the line. Nothing at all usually means TX/RX are swapped, A/B are swapped, or DE/RE are not tied to GPIO25.
  6. On the display: a pulsing heart means the sensor is alive. CHECK SENSOR means it gave no answer for 3 readings in a row.
